# Define the shared visual system

Type: prototype
Status: resolved
Blocked by:

## Question

What visual language and shared-component contract should every module use?

## Answer

Use a restrained, information-dense institutional dashboard: deep teal brand surfaces, mint actions and success states, cool-gray canvas, white cards, hairline borders, compact controls, and minimal shadows. Use 14–16px radii, 16px grid gaps, and 20–24px card padding. Shared primitives live in `packages/ui`; modules compose them and do not fork their styling. The product meets WCAG 2.2 AA and eMAG guidance.
